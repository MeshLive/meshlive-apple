# Privacy label (App Store Connect)

Intent: **Data Not Collected**. Tracking: **No**.

"Collected" here means data that leaves the device in a way the developer or a partner can read for longer than the
request needs. MeshLive has no server and sends nothing to the developer or a third party; calls and livestreams go only
to the other participant, encrypted.

| Data type group | Answer | Reason |
|---|---|---|
| Contact Info | Not collected | No account, profile or address book upload. |
| Health and Fitness | Not collected | The app has no health features. |
| Financial Info | Not collected | No purchases, payments or financial data. |
| Location | Not collected | The app does not request or read location. |
| Sensitive Info | Not collected | The app asks for none. |
| Contacts | Not collected | The system address book is not accessed; verified contacts stay in the app's sealed store on the device. |
| User Content | Not collected | Calls and livestreams go only to the other participant; contacts, recent calls and titles stay on the device. |
| Browsing History | Not collected | The app has no browser. |
| Search History | Not collected | The nearby list filter is local and is not sent anywhere. |
| Identifiers | Not collected | Rotating nearby IDs and node IDs are broadcast to nearby devices, not to the developer; there is no advertising identifier. |
| Purchases | Not collected | The app has no purchases. |
| Usage Data | Not collected | No analytics or usage reporting. |
| Diagnostics | Not collected | The app keeps a short scrubbed crash report on the device and sends it only if the user shares it; the system's own crash sharing is a system setting. |
| Other Data | Not collected | The app collects nothing else. |

**Verify in the form:** the privacy policy page at the URL in `privacy_url.txt` says the same: no account, no server, no
analytics, and data stays on the device.
