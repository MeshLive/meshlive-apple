# Age rating (App Store Connect)

Intent: **18+**. The app has no moderation server and connects strangers for calls and livestreams; the owner chose 18+
rather than a rating computed only from the content the app supplies.

| App Store Connect question | Answer | Reason |
|---|---|---|
| In-app controls: parental controls | No | MeshLive has no parental controls or child accounts. |
| In-app controls: age assurance | No | There is no age check besides the terms statement. |
| Capabilities: unrestricted web access | No | The app opens no browser and has no web view. |
| Capabilities: user-generated content | Yes | Livestreams from nearby people are user-generated. |
| Capabilities: messaging | Yes | Voice and video calls between people; there is no text messaging. |
| Capabilities: advertising | No | No ads. |
| Medical or wellness topics | None | Not a health app. |
| Gambling, contests, loot boxes | No | None. |
| Sexual content or nudity | None | The app supplies no content; user-generated content is covered above. |
| Graphic or realistic violence | None | The app supplies no content; user-generated content is covered above. |
| Cartoon or fantasy violence | None | The app supplies no content. |
| Horror or fear | None | The app supplies no content. |
| Profanity or crude humour | None | The app supplies no content. |
| Alcohol, tobacco or drug references | None | The app supplies no content. |

If App Store Connect computes a rating below 18+, set the **age rating override to 18+**. Reason: calls and livestreams
between strangers, with no moderation server.

**Verify in the form:** the labels change between App Store Connect revisions; the intent is the answers above and the 18+
override.
